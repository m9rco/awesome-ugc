# 调研方法与核验证据

这份文档回答一个问题：**`data/catalog.json` 里的每一条，凭什么在这里？**

## 原则

1. **官方优先**：平台官方站点、官方文档、官方创作者计划 > 社区教程 > 第三方聚合。
2. **实测为准**：每条链接在收录时用 HTTP GET 实测，记录状态码与页面标题；不采信"我印象里有这个站"。
3. **宁缺毋滥**：4xx / 5xx / 标题与主题不符的链接一律不收录，不靠数量凑清单。
4. **不搬运内容**：只指路，不镜像素材、不转载教程正文。
5. **不收录灰色产业**：盗版、破解、外挂、私服、账号交易、代充代刷。

## 核验命令

```sh
curl -s -m 20 -o /tmp/t.html -w '%{http_code}\n' "https://example.com/"
grep -o '<title>[^<]*' /tmp/t.html | head -1
```

直连失败的站点走代理复测，并在条目的 `verified_title` 里保留当时标题：

```sh
export https_proxy=http://127.0.0.1:7897 http_proxy=http://127.0.0.1:7897
```

收录后由 `scripts/check_links.py` 与每周 CI 持续体检：**链接腐烂会被发现，而不是让读者自己撞墙。**

## 调研分轨

本轮按六条轨道并行调研，每轨独立落盘、独立核验：

| 轨道 | 覆盖范围 |
| --- | --- |
| T1 | Roblox / 罗布乐思：UGC 目录、Studio、官方文档、DevForum、创作者分成 |
| T2 | 蛋仔派对：蛋仔工坊、乐园、官方教程、创作者激励 |
| T3 | 元梦之星 / 圆梦之星：命名甄别 + 编辑器与创作者计划 |
| T4 | 奥拉星（含"奥拉热星"命名甄别）、迷你世界、我的世界 |
| T5 | AI 工具链：概念→出图→3D→贴图→放大→抠图→视频→配音→批量→发布 |
| T6 | 生态横切面：可商用素材授权、社区、数据榜单、政策合规 |

## 命名甄别记录

用户口述中出现的名字与公开生态的正式名可能不一致，这类歧义**必须显式记录**，不能悄悄改名：

- **「萝卜lox」** → Roblox，中国版为「罗布乐思」。
- **「圆梦之星」/「元梦之星」** → 见 [`docs/PLATFORMS/dreamstar.md`](PLATFORMS/dreamstar.md) 的甄别结论。
- **「奥拉热星」** → 见 [`docs/PLATFORMS/aola-star.md`](PLATFORMS/aola-star.md) 的甄别结论。

## 已知局限

- 平台侧规格（面数上限、皮肤尺寸、贴图通道、审核细则）会随版本变化，条目**不保证长期有效**，以官方页面为准。
- 部分站点的反爬策略会让自动体检误报，`check_links.py` 的标准是"能取到响应"，不是"页面内容一定正确"。
- 收录不等于推荐接入生产：授权与合规判断请以自己的业务与当地法规为准。
