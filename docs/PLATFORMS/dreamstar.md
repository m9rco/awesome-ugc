# 元梦之星（用户口述的「圆梦之星」）

> **命名说明**：用户原型清单里的"圆梦之星"，据公开资料核对应为腾讯天美工作室的《**元梦之星**》（Dream Star）。本页以"元梦之星"为准，检索时两个词都可能命中。

**定位**：腾讯基于 **UE4** 的派对游戏，UGC 侧是内置编辑器「**星世界**」+「造梦计划」创作者激励。它的差异化在于**官方元件免费、无需解锁**，并专门打包了**国风素材库**，把"找素材"的门槛压到很低。

## 编辑器与创作形态

来源：[开星造梦！《元梦之星》地图编辑器介绍](https://www.taptap.cn/moment/456219695461171265)

- **元件拼装为主**：拿官方元件搭场景，而不是从零建模；
- **面向新手的运动单元**：如**路点运动单元**——选几个点即可生成复杂运动轨迹，本质是把脚本能力包装成可视化操作；
- **可视化编程**：腾讯**扣叮**与元梦之星合作推出可视化编程创作功能（[腾讯云开发者报道](https://cloud.tencent.com/developer/news/1330522)、[中国日报网报道](https://cn.chinadaily.com.cn/a/202403/18/WS65f80148a3109f7860dd5ec6.html)）；
- **新功能持续迭代**：编辑器功能更新有官方视频说明（[bilibili](https://www.bilibili.com/video/BV1mw411j7nU)）；
- **产出可上传模组社区**流通。

## AI：平台侧已经有自研引擎在跑

- 腾讯自研游戏 AI 引擎 **GiiNEX** 的 UGC 工具**已上线《元梦之星》**（[量子位报道](https://www.qbitai.com/2024/03/129590.html)）——这意味着 AI 辅助创作在这条线上是**平台内建**的，优先吃这份红利；
- 对个人作者的直接含义：**AI 出图/辅助逻辑放进编辑器内做，比自己在外面拼管线更省事，也更不容易踩合规线**。

## 创作流程（建议姿势）

1. 在编辑器里**先定玩法骨架**（运动单元 + 触发器），再谈美术；
2. 美术优先用**官方元件 + 国风素材库**，自制只做差异化部分；
3. 逻辑复杂时用**可视化编程**（扣叮）而不是硬写代码；
4. 上传模组社区，参与官方创作活动获取曝光与奖励。
