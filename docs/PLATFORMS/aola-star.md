# 奥拉星（用户口述的「奥拉热星」）

> **命名说明**：用户原型清单里的"奥拉热星"，**在公开产品库里没有找到同名游戏**。按最接近的匹配，本页以百田（百奥游戏）的《**奥拉星**》为准。若你指的是别的产品（例如某个新上线的派对/沙盒项目），欢迎按 [CONTRIBUTING.md](../../CONTRIBUTING.md) 提供线索——本仓库按"有来源才收录"的规矩办事。

**定位**：以**亚比（宠物）养成**为核心的国民主打 IP，横跨页游与手游，生态重心在**玩家社区与同人创作**，而不是"面向外部作者的资产上传通道"。

## 与其它平台的关键差异（据实说明）

目前在公开资料中**没有找到**奥拉星面向外部创作者的：官方资产规格页、编辑器手册、资产上传入口、创作者分成计划。也就是说：

- 这条线上的"做图"主要是**设定图 / 同人图**（画亚比、画拟人、画皮肤创意），产出**不可上架为平台资产**；
- 想把它纳入一条"可交付的资产流水线"，第一步是**确认官方创作入口是否存在、条款是否允许二次创作与商用**；
- 存在被下架/侵权的风险：同人创作不等于获得商用授权。

## 建议的姿态

如果你确实要在这一 IP 上做内容，可复用的通用打法（与平台无关，见[出图工艺](../ART-PIPELINE.md)）：

1. **设定集先行**：把亚比属性/元素/配色整理成自己的"设定表"，再批量出图，风格才统一；
