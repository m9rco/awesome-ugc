# 迷你世界

**定位**：国产沙盒 UGC 平台，创作侧入口是**开发者学院**与**星启计划**，特色是**游戏内建模（微缩模型）**——把"做模型"的门槛压到不需要外部 3D 软件。

## 官方推荐流程（含封面这一常被跳过的步骤）

来源：[开发者学院 · 地图制作流程](https://dev-wiki.mini1.cn/courses/article/955)

1. **申请开发者**：[星启计划](https://activities.mini1.cn/fe/starPlan) → 通过**迷你盒子**激活开发者权限；
2. **建图**：开发者模式下新建地图；官方明确建议用 **PC 桌面版**创作（效率更高）；
3. **场景搭建**：地形编辑器 + 场景元素搭建；
4. **内容扩展**：插件、资源工坊、**微缩模型**（在游戏内制作模型）；
5. **规则与触发器**：把玩法逻辑挂上，这一步决定"能不能玩"而不只是"好不好看"；
6. **保存与发布**：需先转为**玩法地图**再公开上传；
7. **封面**：普通封面**直接在场景里截图**，或**自定义上传图片**；
8. **成长与扶持**：开发者训练营、社区（[开发者服务中心](https://developers.miniworldgame.com)）、**签约工作室扶持**。

## 商业化

- 游戏内货币体系（迷你币/迷你豆）、**开发者商店**、**商业化广告触发器**；
- 海外站有独立的[商业化教程](https://www.miniworldgame.com/zh-hant/news/46)，做海外分发时按当地规则走。

## 出图与美术要点

- **微缩模型的风格边界**：模型在游戏内做，细节受工具能力限制 → 造型策略应"大轮廓 + 贴图细节"，不要在游戏内追求高精度曲面；
- **封面是唯一曝光位**：官方把封面单列一步，说明它直接影响点击率。截图封面要保证在列表缩略图尺寸下主体清晰、明暗对比足够；
- 想外接 3D 制作时，先确认资源导入通道与规格（见开发者学院当期文档）。
