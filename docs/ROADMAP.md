## 下一步

- [ ] **剔除清单留档**：每条调研轨道需留 `rejected` 明细（URL + 状态码 + 剔除理由），补齐"为什么没收录"这半条证据链。
- [ ] **平台规格表**：把各平台的交付物硬约束（皮肤尺寸、贴图通道、面数上限、审核禁区）整理成对照表，标注版本与来源日期。
- [ ] **工序清单可执行化**：把 `docs/AI-WORKFLOW.md` 的每一步落成可运行的脚本或 ComfyUI 工作流，附输入输出样例。
- [ ] **成本核算**：每道工序的 AI 替代方案给出"时间 / 金钱"两条成本线，标明按量计费与本地部署的分界点。
- [ ] **合规专章**：未成年人保护、内容审核红线、AIGC 标识与备案要求的对照表（按平台 + 按地区）。
- [ ] **素材授权速查**：把已收录素材库的授权条款逐条摘录（允许商用 / 需署名 / 禁二次分发），带条款页快照日期。
- [ ] **创作者访谈**：以公开可核验的资料（官方公告、公开直播、公开教程）整理头部作者的流水线，区别于传闻。
- [ ] **英文版补齐**：`README.en.md` 与平台笔记的英文对照。

## 不做

- 不镜像素材、不转载教程正文、不提供下载代理。
- 不收录盗版、破解、外挂、私服、账号交易。
- 不做"AI 神器"排行榜；只按工序落位，并标注失败边界。
